> **One sentence summary:** An activation function is a mathematical
> gate placed after a linear layer that introduces non-linearity —
> without it, stacking a thousand linear layers would collapse into
> a single linear layer, making depth pointless.

---

## 1. The Problem Activation Functions Solve

From [[02. The Linear Layer (MLP) — Many Perceptrons Working Together|The Linear Layer]], we know that a linear layer computes:

$$\mathbf{y} = \mathbf{W}\mathbf{x} + \mathbf{b}$$

Now imagine stacking two linear layers:

$$\mathbf{h} = \mathbf{W}_1\mathbf{x} + \mathbf{b}_1$$
$$\mathbf{y} = \mathbf{W}_2\mathbf{h} + \mathbf{b}_2$$

Substitute the first into the second:

$$\mathbf{y} = \mathbf{W}_2(\mathbf{W}_1\mathbf{x} + \mathbf{b}_1) + \mathbf{b}_2$$
$$\mathbf{y} = \underbrace{(\mathbf{W}_2\mathbf{W}_1)}_{\mathbf{W}^*}\mathbf{x} + \underbrace{(\mathbf{W}_2\mathbf{b}_1 + \mathbf{b}_2)}_{\mathbf{b}^*}$$

Two stacked linear layers are **mathematically identical to one
linear layer** with weights $\mathbf{W}^* = \mathbf{W}_2\mathbf{W}_1$.

This means no matter how many linear layers you stack, the entire
network collapses to a single linear transformation. The model can
only learn straight lines — no curves, no complex decision
boundaries, no sign language recognition.

**The fix:** Place a non-linear function between layers that cannot
be absorbed into a matrix multiplication.

---

## 2. The Intuition — The Light Switch Problem

Imagine you are trying to decide if a photo contains a cat.
A linear model can only draw one straight line through the feature
space. If cats and non-cats are not linearly separable (which they
never are in real data), a linear model fails by design.

Non-linearity gives the model the ability to draw curved, twisted,
complex boundaries. Each activation function adds a "bend" to the
decision surface.

**Simple analogy:** A straight ruler can only draw straight lines.
Add a hinge (activation function) and suddenly you can draw any
angle. Add many hinges and you can approximate any curve.

## 3. ReLU — Rectified Linear Unit

### The Formula

$$\text{ReLU}(x) = \max(0, x)$$

### What It Does

- If $x > 0$: pass it through unchanged
- If $x \leq 0$: kill it (output 0)

```text
Input x:       -3.0  -1.5   0.0  +1.2  +3.8  +5.1
ReLU output:    0.0   0.0   0.0  +1.2  +3.8  +5.1
```

### Visual

![[Pasted image 20260416224825.png|563]]

Flat on the left (negative inputs → 0).
Straight line on the right (positive inputs pass through).

### Why It Works

**ReLU** creates a **binary gate** for each neuron:
- Gate OPEN: if the weighted sum is positive → pass the signal
- Gate CLOSED: if the weighted sum is negative → block the signal

After training, each neuron in a **ReLU** network specialises in
detecting a specific pattern. If the pattern is present (positive
activation) the neuron fires. If absent (negative activation) it
stays silent.

### The "Dying ReLU" Problem

**ReLU** has one weakness: if a neuron's weighted sum is consistently
negative across all training examples, it **never fires**. Its
gradient is permanently zero and it can never update its weights.
It "dies." In large networks, 10-30% of neurons can die during
training.

This is one reason your model uses GELU instead of ReLU.

---

## 4. GELU — Gaussian Error Linear Unit

### The Formula

$$\text{GELU}(x) = x \cdot \Phi(x)$$

where $\Phi(x)$ is the cumulative distribution function (CDF)
of the standard normal distribution:

$$\Phi(x) = \frac{1}{2}\left[1 + \text{erf}\!\left(\frac{x}{\sqrt{2}}\right)\right]$$

In practice, a fast approximation is used:

$$\text{GELU}(x) \approx 0.5x\left(1 + \tanh\!\left[\sqrt{\frac{2}{\pi}}(x + 0.044715x^3)\right]\right)$$

### What It Does

GELU is a **smooth, probabilistic gate**. Instead of a hard
binary decision (fire or die), it asks:

> "Given this input value $x$, what is the probability that a
> standard normal random variable would also be smaller than $x$?
> Weight the signal by that probability."

```text
Input x:         -3.0   -2.0   -1.0   0.0   +1.0  +2.0  +3.0
Φ(x) prob:        0.13%  2.3%  15.9%  50%   84.1%  97.7%  99.9%
GELU output:     -0.004 -0.046 -0.159  0.0  +0.841 +1.954 +2.997
```

### Visual — GELU vs ReLU

```text
Output
  │                      GELU ≈ ReLU for large x
  │                 __,------
  │            ___/
  │      _____/          ← GELU (smooth curve)
──┼─────/─────────────── Input
  │   _/ ←small negative region
  │__/   (GELU dips slightly below 0)
```

![[Pasted image 20260416225109.png|390]]

Key difference: GELU has a **small negative region** around $x\approx -0.17$ (it outputs $\approx -0.17$ at its minimum before approaching 0). This prevents complete neuron death.

### Why GELU is Better for Transformers

| Property | ReLU | GELU |
|---|---|---|
| Negative inputs | Exactly 0 | Slightly negative (smooth) |
| Gradient at negative inputs | 0 (neuron dies) | Non-zero (neuron stays alive) |
| Boundary | Hard (sharp kink at 0) | Smooth (differentiable everywhere) |
| Empirical performance | Good for CNNs | **Better for Transformers** |

The smoothness matters enormously for Transformers. The attention
mechanism produces continuous distributions. A hard binary gate
(ReLU) would create discontinuities that make the loss landscape
harder to navigate. GELU's smooth curve makes gradient flow
cleaner throughout the entire network.

This is why every major Transformer — BERT, GPT, T5, and your
ASLTransformer — uses GELU rather than ReLU.

## 5. A Concrete Example — What Happens to One Number

Let us trace one value through the projection and activation in
your model.

**Scenario:** After the linear projection, feature $j=42$ of
frame $t=20$ has value $-0.3$. This might represent "left hand
is slightly below baseline position" — a weak, ambiguous signal.

**With ReLU:**
$$\text{ReLU}(-0.3) = \max(0, -0.3) = 0.0$$

The signal is completely erased. The CNN and Transformer will
never see any information from this feature for this frame.

**With GELU:**
$$\text{GELU}(-0.3) = -0.3 \times \Phi(-0.3) \approx -0.3 \times 0.382 = -0.115$$

The signal is **attenuated but preserved**. The downstream layers
receive a weak negative signal — not a zero. They can still use
the information that "something slightly below baseline happened
here."

For your ASL project, this matters because many ASL signs involve
subtle movements where the hand passes through ambiguous positions
between the start and end of a gesture. ReLU would erase these
intermediate positions. GELU preserves them at reduced strength.

## 6. Where Activation Functions Appear in our Model

```text
Stage 1: Linear Projection
    Linear(345 → 256)
    LayerNorm
    (no activation — LayerNorm handles stability)

Stage 2: 1D-CNN
    Conv1d → GELU ← here
    Dropout
    Conv1d → GELU ← here
    Dropout

Stage 4: Transformer Feed-Forward Block
    Linear(256 → 1024) → GELU ← here
    Linear(1024 → 256)

Stage 5: Classification Head
    Linear(256 → 256) → GELU ← here
    Dropout
    Linear(256 → 250)
    (no activation — raw logits go to CrossEntropyLoss)
```

**GELU appears 4 times** in our model. Each one introduces
a non-linearity that allows the subsequent layer to compute
more complex functions of its inputs.

## 7. What Happens Without Any Activation Function

If you remove all GELU calls from your model, the 1D-CNN and
feed-forward blocks collapse into single linear layers.
The entire model from input to output becomes:

$$\hat{\mathbf{y}} = \mathbf{W}_{\text{total}}\mathbf{x} + \mathbf{b}_{\text{total}}$$

One giant matrix multiplication. Linear in, linear out.
No matter how complex the sign is, the model can only separate
classes with a hyperplane in 345-dimensional space.

In practice, removing activations from our model would likely
drop test accuracy from 46% to approximately 5-10% — barely
above the random baseline of 0.4%.

## 8. Why Not Use Other Activation Functions?

Many activation functions exist. Here is why we use GELU
specifically:

| Function | Formula | Problem for Your Use Case |
|---|---|---|
| Sigmoid | $1/(1+e^{-x})$ | Saturates at 0 and 1 → vanishing gradients in deep networks |
| Tanh | $(e^x - e^{-x})/(e^x + e^{-x})$ | Also saturates, same problem |
| ReLU | $\max(0,x)$ | Dying neurons, hard boundary hurts Transformer training |
| Leaky ReLU | $\max(0.01x, x)$ | Better than ReLU but not as smooth as GELU |
| **GELU** | $x \cdot \Phi(x)$ | ✓ Smooth, no saturation, no dying neurons |
| Swish | $x \cdot \sigma(x)$ | Very similar to GELU, interchangeable |

GELU was introduced by Hendrycks & Gimpel (2016) and has become
the standard for Transformer architectures since BERT (2018)
demonstrated its superiority over ReLU for attention-based models.

## 9. The Practical Impact on our Results

Here is the honest answer to your question: **how much do they
help our cause specifically?**

In the model, removing GELU from all four locations and replacing
with identity (no activation) would likely:

- Collapse the 1D-CNN into a single linear filter (no velocity
  or acceleration detection)
- Collapse the feed-forward block into a linear projection
  (Transformer loses 75% of its representational power)
- Collapse the classification head into a single linear layer

The Transformer architecture's power comes from the combination
of self-attention (captures which frames to look at) and the
feed-forward block (computes what to do with that attended
information). Remove GELU from the feed-forward block and the
Transformer becomes a glorified attention-weighted average with
a linear classifier on top.

Empirically, GELU vs ReLU in a Transformer makes approximately
1-3% accuracy difference on most benchmarks. But removing
activations entirely is catastrophic — the difference between
46% and effectively random.

## 11. The Formula to Remember

$$\boxed{\text{GELU}(x) = x \cdot \Phi(x)}$$

Read as: "pass $x$ through, but weight it by the probability that
a standard normal variable would be less than $x$."

Large positive $x$ → probability ≈ 1 → passes through fully.
Large negative $x$ → probability ≈ 0 → nearly blocked.
Near zero $x$ → probability ≈ 0.5 → half strength.

# 12. History and Deeper explanations

## The Historical Problem That Created ReLU

Go back to 1986. Neural networks exist but they are essentially useless for deep networks. The reason is the **vanishing gradient problem**.

Training uses backpropagation — gradients flow backward from the loss through every layer. The gradient of a layer gets multiplied by the gradient of the layer before it, then multiplied again, and again.

If each multiplication makes the number slightly smaller, by the time you reach the first layer, the gradient has been multiplied 10, 20, 50 times by small numbers. It becomes essentially zero.

$$\frac{\partial \mathcal{L}}{\partial w_1} = \underbrace{0.8 \times 0.8 \times 0.8 \times \cdots \times 0.8}_{50 \text{ layers}} \approx 0.000014$$

The first layers learn nothing. Deep networks were useless.

---

## Why Sigmoid Was the Default and Why It Killed Deep Networks

The activation function everyone used before ReLU was **sigmoid**:

$$\sigma(x) = \frac{1}{1 + e^{-x}}$$

It maps any input to $(0, 1)$. Biologically inspired — neurons either fire or do not.

But look at its gradient:

$$\sigma'(x) = \sigma(x)(1 - \sigma(x))$$

The maximum value of $\sigma'(x)$ is $0.25$ — at $x = 0$.

For any input far from zero, the gradient is nearly zero:

```text
x = -5:  σ'(-5) ≈ 0.007
x = -3:  σ'(-3) ≈ 0.045
x =  0:  σ'( 0) = 0.250  ← maximum
x = +3:  σ'(+3) ≈ 0.045
x = +5:  σ'(+5) ≈ 0.007
```

Multiply 50 of these together and you get essentially zero. The vanishing gradient problem was caused by the activation function itself.

---

## The Insight That Created ReLU

In 2010, Nair and Hinton asked a simple question:

> **What if the gradient of the activation function was just 1?**

If the gradient is 1, then multiplying 50 of them gives 1. No vanishing. The gradient at layer 1 is the same magnitude as the gradient at layer 50.

The simplest function with gradient 1 everywhere is the **identity function**: $f(x) = x$. But that gives you no non-linearity — back to the collapsing-to-one-layer problem.

So the question became: **can we have gradient = 1 AND non-linearity?**

The answer is yes — just use the identity function for positive values and zero for negative values:

$$\text{ReLU}(x) = \begin{cases} x & \text{if } x > 0 \\ 0 & \text{if } x \leq 0 \end{cases}$$

The gradient is:

$$\text{ReLU}'(x) = \begin{cases} 1 & \text{if } x > 0 \\ 0 & \text{if } x \leq 0 \end{cases}$$

When the neuron is active (positive input), gradient = 1 exactly. No vanishing. The signal flows backward perfectly.

---

## Why Zero for Negative Values?

This is the part nobody explains well. Why not use $f(x) = x$ for all values (which would be linear and useless) or something else for negative values?

The answer comes from **sparse representations**.

The human brain has approximately 86 billion neurons. At any given moment, only about 1-4% are firing. The rest are silent. This sparsity is not a bug — it is a feature. Sparse activations mean:

1. **Efficiency** — most neurons are doing nothing most of the time
2. **Specialisation** — each neuron learns to respond to very specific patterns
3. **Disentanglement** — different features do not interfere with each other

ReLU enforces sparsity by killing all negative activations. After a ReLU layer, typically 50% of neurons output exactly zero. This creates a sparse, specialised representation.

With sigmoid, every neuron always outputs a non-zero value between 0 and 1. Every neuron is always partially active. Nothing is ever truly off. The representations are dense and entangled — harder to separate.

---

## The Biological Connection — Why It Actually Makes Sense

Real biological neurons have a threshold. Below the threshold: silence. Above the threshold: firing proportional to stimulus strength.

```text
Biological neuron:
  Stimulus < threshold → no signal
  Stimulus ≥ threshold → signal proportional to stimulus

ReLU:
  Input < 0 → output = 0
  Input ≥ 0 → output = input
```

ReLU is a mathematical idealisation of the biological neuron's threshold behaviour. Not a perfect model — but the right abstraction for gradient flow.

---

## Now Why GELU for Transformers Specifically

Here is where it gets deep.

In a CNN, the input to each activation function is a **convolution output** — a local spatial feature detector. These features are roughly binary: either the pattern is present in this local region or it is not. Hard gating (ReLU) makes sense. You want neurons to clearly fire or not fire based on whether the convolution detected its target pattern.

In a Transformer, the input to each activation function inside the feed-forward block is something fundamentally different. It is a **globally-attended representation** — a mixture of information from all 64 frames, weighted by how much the model decided each frame should attend to every other frame. This representation is continuous, dense, and uncertain.

The feed-forward block in the Transformer is not asking "is this pattern present?" It is asking "given everything the attention mechanism just computed about the global structure of this sign, what should I conclude?"

For that kind of computation, a **hard binary decision** (ReLU) is the wrong tool. You want a **probabilistic, smooth decision**:

> "How confident am I that this attended signal is meaningful? Weight it proportionally to that confidence."

That is exactly what GELU computes:

$$\text{GELU}(x) = x \cdot \underbrace{\Phi(x)}_{\text{confidence that } x \text{ is signal, not noise}}$$

$\Phi(x)$ is the probability that a standard normal variable is less than $x$. Interpreted intuitively:

- Large positive $x$: very likely to be real signal → passes through almost unchanged
- Near zero $x$: uncertain whether signal or noise → attenuated to half strength
- Negative $x$: likely to be noise → strongly suppressed but not completely killed

This probabilistic weighting is the right operation for a component (the feed-forward block) that must reason about uncertain, globally-aggregated information.

---

## The Deepest Reason — Information Theory

There is a beautiful information-theoretic argument for why smooth activation functions are better for attention-based models.

The attention mechanism computes:

$$\text{Attention} = \text{softmax}\!\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}}\right)\mathbf{V}$$

Softmax is a smooth, differentiable function. It distributes probability mass smoothly across all frames. The output of attention is therefore a smooth, continuous mixture of value vectors.

When you pass this smooth mixture through a hard non-linearity like ReLU, you introduce a discontinuity. The gradient has a hard jump at zero. This creates a mismatch between the smooth information landscape that attention produces and the sharp decision boundary that ReLU imposes.

GELU is smooth and differentiable everywhere. It has no discontinuities. Its gradient never jumps. This preserves the geometric structure of the attention output and makes the loss landscape smoother — which means gradient descent converges faster and more reliably.

---

## Concrete Impact in our Model

Our 1D-CNN uses GELU to process local motion features. After the convolution detects velocity patterns between adjacent frames, GELU decides how strongly to pass each detected pattern to the Transformer. The probabilistic gating means subtle velocity signals (near zero) are not killed — they are attenuated. The Transformer can still detect them and decide whether they matter.

The Transformer feed-forward block uses GELU to process the globally-attended representation. After self-attention aggregates information across all 64 frames, GELU filters the result before projecting back to 256 dimensions. The smooth gating preserves the continuous structure of the attended representation.

If you replaced both with ReLU:
- Subtle velocity signals in the CNN would be killed at zero
- The feed-forward block would impose hard binary decisions on continuous attention outputs
- The loss landscape would become more jagged
- Training would be less stable and likely converge to a worse solution

The empirical difference on your dataset is probably 1-3% accuracy. But on top of that, training would take longer and be less stable — which at 30 minutes per experiment is a real cost.

---

## Summary in One Paragraph

ReLU was invented to solve the vanishing gradient problem by giving the active neurons a gradient of exactly 1 — no shrinking, no saturation. The zero for negative inputs was a deliberate design choice to enforce sparsity, making each neuron specialise in specific patterns. GELU was invented because Transformers produce continuous, uncertain, globally-aggregated representations that deserve probabilistic rather than binary gating — the smooth curve of GELU preserves the geometric structure that attention creates, while ReLU's hard boundary would destroy it.
