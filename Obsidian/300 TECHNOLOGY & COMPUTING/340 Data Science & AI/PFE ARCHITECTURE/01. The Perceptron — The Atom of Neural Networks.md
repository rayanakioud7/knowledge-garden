## 1. The Intuition — No Math Yet

Before neural networks. Before Transformers. Before any of this.
There is one thing: the **perceptron**.

A perceptron is a **decision maker**. It looks at several pieces
of information at the same time and produces a single verdict.

### Real Example: Should I Bring an Umbrella?

Imagine you are deciding whether to bring an umbrella today.
You look at three pieces of information:

| Input | Symbol | Example value |
|---|---|---|
| Is it cloudy? | $x_1$ | 1 (yes) |
| What is the humidity? | $x_2$ | 0.85 |
| Did it rain yesterday? | $x_3$ | 0 (no) |

You do not treat these three things equally. You have a personal
intuition about how much each one matters:

```text
umbrella_score = (cloudiness  × 0.3)
               + (humidity    × 0.5)
               + (rained_yest × 0.2)
               + 0.1
```

The values 0.3, 0.5, 0.2 are your **weights** — how much you
trust each signal. The 0.1 at the end is a **bias** — a baseline
tendency that nudges the score up or down regardless of the inputs.

Computing this for the example above:

```text
umbrella_score = (1 × 0.3) + (0.85 × 0.5) + (0 × 0.2) + 0.1
               = 0.3 + 0.425 + 0.0 + 0.1
               = 0.825
```

If `umbrella_score > 0.5` → bring umbrella.
If `umbrella_score ≤ 0.5` → leave it at home.

**That is a perceptron.**

## 3. The Mathematics

### Scalar Form

$$y = w_1 x_1 + w_2 x_2 + w_3 x_3 + b$$

For $n$ inputs this generalises to:

$$y = \sum_{i=1}^{n} w_i x_i + b$$

### Vector Form

When you have many inputs, writing them out one by one is tedious.
We collect all inputs into a vector $\mathbf{x}$ and all weights
into a vector $\mathbf{w}$:

$$\mathbf{x} = \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix},
\quad
\mathbf{w} = \begin{bmatrix} w_1 \\ w_2 \\ w_3 \end{bmatrix}$$

The weighted sum is then a **dot product**:

$$y = \mathbf{w}^\top \mathbf{x} + b$$

The $\top$ symbol means "transpose" — we flip $\mathbf{w}$
from a column vector to a row vector so the multiplication works:

$$\mathbf{w}^\top \mathbf{x} =
\begin{bmatrix} w_1 & w_2 & w_3 \end{bmatrix}
\begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix}
= w_1 x_1 + w_2 x_2 + w_3 x_3$$

### What Each Symbol Means

| Symbol | Name | Role |
|---|---|---|
| $\mathbf{x} \in \mathbb{R}^n$ | Input vector | The data you feed in |
| $\mathbf{w} \in \mathbb{R}^n$ | Weight vector | Learned importance of each input |
| $b \in \mathbb{R}$ | Bias | Learned baseline offset |
| $y \in \mathbb{R}$ | Output (scalar) | The perceptron's verdict |

---

## 4. What Does the Bias Do?

Without bias:

$$y = w_1 x_1 + w_2 x_2 + w_3 x_3$$

If all inputs are zero ($x_1 = x_2 = x_3 = 0$), the output
is always exactly 0. The perceptron cannot output anything
useful when all signals are absent.

With bias:

$$y = w_1 x_1 + w_2 x_2 + w_3 x_3 + b$$

If all inputs are zero, the output is $b$ — a meaningful baseline.

**Analogy:** Think of bias as the perceptron's default opinion
before it sees any evidence. Someone who is naturally pessimistic
has a negative bias. Someone optimistic has a positive bias.

## 5. What Makes a Perceptron "Learn"?

The weights and bias **start random**. They are not designed by
anyone — they are initialised with small random numbers and then
**adjusted iteratively using data**.

The learning process works like this:

```text
1. Show the perceptron an example (e.g., a rainy day)
2. It makes a prediction using current weights
3. Compare prediction to the true answer
4. Measure the error (how wrong was it?)
5. Adjust weights slightly in the direction that reduces error
6. Repeat with the next example
7. After thousands of examples, weights stabilise at values
   that produce correct predictions most of the time
```

This adjustment process is called **gradient descent**.
The rule for updating each weight is:

$$w_i \leftarrow w_i - \eta \cdot \frac{\partial \mathcal{L}}{\partial w_i}$$

Where:
- $\eta$ (eta) is the **learning rate** — how big each step is
- $\frac{\partial \mathcal{L}}{\partial w_i}$ is the **gradient** —
  which direction to move weight $w_i$ to reduce the error $\mathcal{L}$

> **Key insight:** No human programs what the weights should be.
> The perceptron discovers the right weights by looking at data
> and adjusting to reduce its mistakes.

## 6. The Limitation of a Single Perceptron

A single perceptron can only learn **linear** relationships —
straight lines (in 2D) or flat hyperplanes (in higher dimensions).

### Example of what it can learn:

```text
"If humidity is high AND it is cloudy, then rain"
→ This is a linear combination of inputs ✓
```

### Example of what it cannot learn:

```text
"Rain only if EXACTLY ONE of the two conditions is true, not both"
→ This is the XOR problem — not linearly separable ✗
```

Real-world problems like sign language recognition are vastly
more complex than any linear relationship can capture.
The solution: **stack many perceptrons together** and introduce
**non-linear activation functions** between layers.

This gives us the **neural network**.

## 7. Connection to the ASL Project (PFE)

In your model, the first operation is the **Linear Projection**:

$$\mathbf{H}^{(0)} = \mathbf{X} \mathbf{W}_{\text{proj}} + \mathbf{b}$$

This is exactly a perceptron — but scaled up dramatically:

| Umbrella perceptron | Your linear projection |
|---|---|
| 3 inputs | **345 inputs** (landmark coordinates) |
| 1 output | **256 outputs** (d_model features) |
| 3 weights | **345 × 256 = 88,320 weights** |
| 1 bias | **256 biases** (one per output) |

Each of the 256 output values is produced by one perceptron
operating on all 345 inputs simultaneously.

And just like the umbrella example, none of the 88,320 weights
are set by hand. They are all **learned from the 74,841 training
sign sequences** — adjusting themselves over 79 epochs until they
produce features that help distinguish between the 250 ASL signs.

## 8. Summary

| Concept | One-line definition |
|---|---|
| **Input** $\mathbf{x}$ | The raw numbers going in |
| **Weight** $\mathbf{w}$ | Learned importance of each input |
| **Bias** $b$ | Learned baseline offset |
| **Output** $y = \mathbf{w}^\top \mathbf{x} + b$ | Weighted sum of inputs |
| **Learning** | Adjusting weights to reduce prediction error |
| **Limitation** | Can only learn linear relationships |
| **Solution** | Stack many perceptrons → neural network |

---

## 9. One Equation to Remember

$$\boxed{y = \mathbf{w}^\top \mathbf{x} + b}$$

This is the foundation of every neural network ever built.
Every layer in your ASL Transformer — the linear projection,
the feed-forward blocks, the classification head — is built
from this one operation, applied at different scales and
combined with non-linearities.
