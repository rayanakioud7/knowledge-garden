## 1. Rappel et Principe des Fonctions SQL

> [!abstract] Résumé : Ordre SELECT complet (leçons précédentes)
> ```sql
> SELECT [DISTINCT] {*, column [alias], ...}
> FROM table
> [WHERE condition(s)]
> [ORDER BY {column, expr, alias} [ASC | DESC]];
> ```

> [!info] Définition : Fonction SQL
> Une fonction prend des **entrées** (arguments `arg 1`, `arg 2`, …, `arg n`), **exécute une action**, et produit une **sortie** (valeur résultante).

> ![[{5668F5A4-8562-4C47-8206-3ACE8263CF8A}.png]]

> [!info] Définition : Deux types de fonctions SQL
> - **Fonctions mono-ligne** : agissent sur chacune des lignes rapportées ;
> - **Fonctions multi-lignes** : agrègent plusieurs lignes (objet d'un chapitre ultérieur).

### Caractéristiques des Fonctions Mono-Ligne

> [!info] Définition : Fonctions mono-ligne
> - Manipulent des éléments de données ;
> - Acceptent des arguments et ramènent **une valeur** ;
> - Agissent sur **chacune** des lignes rapportées ;
> - Ramènent **un seul résultat par ligne** ;
> - Peuvent **modifier les types de données** ;
> - Peuvent être **imbriquées**.

> [!abstract] Catégories des fonctions mono-ligne
> **Caractère** · **Numérique** · **Date** · **Conversion** · **Générales**

## 2. Fonctions Caractère

### 2.1 Fonctions de Conversion Majuscules/Minuscules

| Fonction | Résultat |
| :--- | :--- |
| `LOWER('Cours SQL')` | `cours sql` |
| `UPPER('Cours SQL')` | `COURS SQL` |
| `INITCAP('Cours SQL')` | `Cours Sql` |

> [!example] Exemple d'Application : Recherche insensible à la casse (employé Blake)
> « Afficher le matricule, le nom et le numéro de département de l'employé Blake. »
> ```sql
> SQL> SELECT empno, ename, deptno
>   2  FROM emp
>   3  WHERE ename='blake';
> no rows selected
>
> SQL> SELECT empno, ename, deptno
>   2  FROM emp
>   3  WHERE LOWER(ename)='blake';
> EMPNO  ENAME  DEPTNO
> ----------------------------
> 7698   BLAKE  30
> ```
> **Lecture :** la valeur stockée est `BLAKE` ; la comparaison directe avec `'blake'` échoue (le SQL de comparaison est sensible à la casse) ; `LOWER(ename)` normalise la colonne avant comparaison.

### 2.2 Fonctions de Manipulation des Caractères

| Fonction | Résultat |
| :--- | :--- |
| `CONCAT('Une','Chaîne')` | `UneChaîne` |
| `SUBSTR('Chaîne',1,3)` | `Cha` |
| `LENGTH('Chaîne')` | `6` |
| `INSTR('Chaîne','a')` | `3` |
| `LPAD(sal,10,'*')` | `******5000` |

> [!example] Exemple d'Application : Vendeurs filtrés par `SUBSTR`
> ```sql
> SQL> SELECT ename, CONCAT(ename, job), LENGTH(ename),
>   2  INSTR(ename,'A')
>   3  FROM emp
>   4  WHERE SUBSTR(job,1,5)='SALES';
> ENAME   CONCAT(ENAME,JOB)   LENGTH(ENAME)  INSTR(ENAME,'A')
> ----------------------------------------------------------
> MARTIN  MARTINSALESMAN      6              2
> ALLEN   ALLENSALESMAN       5              1
> TURNER  TURNERSALESMAN      6              0
> WARD    WARDSALESMAN        4              2
> ```
> **Lecture :** `INSTR` renvoie `0` lorsque le caractère cherché est absent (cas de `TURNER`).

## 3. Fonctions Numériques

> [!info] Définition : ROUND et MOD
> - **ROUND** : permet soit d'arrondir sans décimale pour retourner un nombre entier (aucun chiffre après la virgule), soit de choisir le nombre de chiffres après la virgule ;
> - **MOD** : ramène le **reste** d'une division.

| Expression | Résultat |
| :--- | :--- |
| `ROUND(45.926)` | `46` |
| `ROUND(45.926, 2)` | `45.93` |
| `ROUND(45.923, 2)` | `45.92` |
| `MOD(1600, 300)` | `100` |

> [!example] Exemple d'Application : Reste du salaire par la commission (vendeurs)
> « Calculer le reste de la division salaire par commission pour l'ensemble des employés ayant un poste de vendeur. »
> ```sql
> SQL> SELECT ename, sal, comm, MOD(sal, comm)
>   2  FROM emp
>   3  WHERE job='SALESMAN';
> ENAME   SAL    COMM   MOD(SAL,COMM)
> -----------------------------------------
> MARTIN  1250   1400   1250
> ALLEN   1600   300    100
> TURNER  1500   0      1500
> WARD    1250   500    250
> ```

> [!warning] Piège / Cas Particulier : `MOD` avec diviseur nul
> Mathématiquement, le modulo par $0$ est indéfini. Oracle renvoie ici le dividende : `MOD(1500, 0) = 1500` (ligne TURNER). Ne jamais dépendre de ce comportement dans un code portable.

## 4. Opérations Arithmétiques sur les Dates

> [!info] Définition : Arithmétique des dates
> - **Ajout ou soustraction d'un nombre à une date** pour obtenir un résultat de type **date** ;
> - **Soustraction de deux dates** afin de déterminer le **nombre de jours** entre ces deux dates.

> [!example] Exemple d'Application : Ancienneté en semaines (département 10)
> ```sql
> SQL> SELECT ename, DATEDIFF(SYSDATE(),hiredate)/7 WEEKS
>   2  FROM emp
>   3  WHERE deptno= 10;
> ENAME   WEEKS
> -------------------
> KING    830.93709
> CLARK   853.93709
> MILLER  821.36566
> ```
> **Lecture :** `SYSDATE() - hiredate` donne un nombre de **jours** ; la division par $7$ convertit en semaines.

## 5. Fonctions de Conversion

> [!info] Définition : Conversions implicite et explicite
> - **Conversion implicite** de types de données : effectuée automatiquement par le serveur ;
> - **Conversion explicite** : imposée par le développeur via les fonctions de conversion.

> ![[{1CA16E78-8CE2-4BE4-BABF-A76B8DD7E1CB}.png]]

### Modèles de Format Date

| Modèle | Signification |
| :---: | :--- |
| `YYYY` | Année exprimée avec 4 chiffres |
| `YEAR` | Année exprimée en toutes lettres |
| `MM` | Mois exprimé avec 2 chiffres |
| `MONTH` | Mois exprimé en toutes lettres |
| `DY` | 3 premières lettres du nom du jour |
| `DAY` | Jour exprimé en toutes lettres |

> [!example] Exemple d'Application : `TO_CHAR` avec les dates
> ```sql
> SQL> SELECT ename,
>   2  TO_CHAR(hiredate,'fmDD Month YYYY') HIREDATE
>   3  FROM emp;
> ENAME   HIREDATE
> ---------------------------
> KING    17 November 1981
> BLAKE   1 May 1981
> CLARK   9 June 1981
> JONES   2 April 1981
> MARTIN  28 September 1981
> ALLEN   20 February 1981
> ...
> 14 rows selected.
> ```
> **Lecture :** le préfixe `fm` supprime le remplissage (zéros et espaces de padding) du format.

## 6. Fonction NVL

> [!info] Définition : NVL
> Convertit une valeur **NULL** en une valeur **réelle**.
> - Fonctionne avec les données de type **date**, **caractère** et **numérique** ;
> - **Les types de données doivent correspondre :**
>   - `NVL(comm,0)`
>   - `NVL(hiredate, ' 01-JAN-97 ')`
>   - `NVL(job, ' No Job Yet ')`

> [!example] Exemple d'Application : Salaire annuel total commission incluse
> ```sql
> SQL> SELECT ename, sal, comm,(sal*12)+NVL(comm,0)
>   2  FROM emp;
> ENAME   SAL    COMM   (SAL*12)+NVL(COMM,0)
> ------------------------------------------------
> KING    5000          60000
> BLAKE   2850          34200
> CLARK   2450          29400
> JONES   2975          35700
> MARTIN  1250   1400   16400
> ALLEN   1600   300    19500
> ...
> 14 rows selected.
> ```

> [!warning] Piège / Cas Particulier : Propagation de NULL
> Sans `NVL`, toute expression arithmétique contenant `NULL` est évaluée à `NULL` : `(sal*12)+comm` donnerait `NULL` pour KING. `NVL(comm,0)` neutralise la propagation et rend le calcul possible.

## 7. Fonctions Conditionnelles : CASE et DECODE

### 7.1 La Fonction CASE

> [!info] Définition : CASE
> Facilite les recherches conditionnelles.
> ```sql
> CASE WHEN condition1 THEN result1
>      WHEN condition2 THEN result2
>      WHEN conditionN THEN resultN
>      ELSE result
> END;
> ```

> [!example] Exemple d'Application : CASE sur une quantité
> ```sql
> SELECT OrderID, Quantity,
> CASE
>     WHEN Quantity> 30 THEN "The quantity is greater than 30"
>     WHEN Quantity= 30 THEN "The quantity is 30"
>     ELSE "The quantity is under 30"
> END
> FROM OrderDetails;
> ```

### 7.2 La Fonction DECODE

> [!info] Définition : DECODE
> Facilite les recherches conditionnelles en jouant le rôle de `CASE` ou `IF-THEN-ELSE`.
> ```sql
> DECODE(col/expression, search1, result1
>        [, search2, result2,...,]
>        [, default])
> ```

> [!example] Exemple d'Application : DECODE dans Oracle (salaires révisés)
> ```sql
> SQL> SELECT job, sal,
>   2  DECODE(job,'ANALYST', SAL*1.1,
>   3         'CLERK',  SAL*1.15,
>   4         'MANAGER', SAL*1.20,
>   5         SAL)
>   6  REVISED_SALARY
>   7  FROM emp;
> JOB        SAL    REVISED_SALARY
> --------------------------------
> PRESIDENT  5000   5000
> MANAGER    2850   3420
> MANAGER    2450   2940
> ...
> 14 rows selected.
> ```
> **Lecture :** `ANALYST` → $+10\%$ ; `CLERK` → $+15\%$ ; `MANAGER` → $+20\%$ ; défaut (`SAL`) → salaire inchangé (PRESIDENT reste à 5000). Vérification : $2850 \times 1.20 = 3420$ ; $2450 \times 1.20 = 2940$.

## 8. Imbrication des Fonctions

> [!info] Définition / Théorème : Imbrication
> - Le niveau d'imbrication des fonctions mono-ligne est **illimité** ;
> - Les fonctions imbriquées sont évaluées **de l'intérieur vers l'extérieur** :
> $$
> F3\big(F2\big(F1(col, arg_1), arg_2\big), arg_3\big)
> $$
> - **Etape 1** = Résultat 1 (évaluation de $F1$) ;
> - **Etape 2** = Résultat 2 (évaluation de $F2$) ;
> - **Etape 3** = Résultat 3 (évaluation de $F3$).
