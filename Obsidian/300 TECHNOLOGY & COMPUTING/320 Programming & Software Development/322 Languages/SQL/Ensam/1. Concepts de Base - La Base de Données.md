## 1. Concepts de Base : La Base de Données

> [!info] Définition : Base de données
> Une base de données est une collection d'informations organisées afin d'être facilement consultables, gérables et mises à jour.
> 
> 

### Structure Logique (MySQL)

Une base de données contient plusieurs **Tables**.
Une table est composée de :

* **Champs (Colonnes) :** Représentent les attributs ou propriétés de la donnée (ex: `Champ 1`, `Champ 2`).


* **Entrées (Lignes / Enregistrements) :** Représentent les occurrences réelles des données.

## 2. L'Ordre SQL `SELECT` Élémentaire

L'instruction `SELECT` est le cœur du langage SQL (Structured Query Language).

### Syntaxe Générale

```sql
SELECT [DISTINCT] {*, column [alias], ...}
FROM table;

```


* `SELECT` indique **quelles colonnes** rapporter (projection).


* `FROM` indique dans **quelle table** rechercher.



### Règles d'Écriture des Ordres SQL

> [!abstract] Bonnes Pratiques
> * Le SQL est **insensible à la casse** (peut être écrit en majuscules ou minuscules).
> 
> 
> * Les ordres peuvent être écrits sur **plusieurs lignes**.
> 
> 
> * Les mots-clés ne doivent **jamais** être abrégés ou coupés sur deux lignes.
> 
> 
> * Utilisez les tabulations et l'indentation pour une meilleure lisibilité.
> 
> 
> 
>

## 3. Projection et Sélection de Colonnes

### Sélectionner Toutes les Colonnes

L'opérateur `*` (étoile) permet de ramener toutes les colonnes d'une table.

```sql
SELECT *
FROM dept;

```

### Sélectionner des Colonnes Spécifiques

Séparez les noms des colonnes par des virgules.

```sql
SELECT deptno, loc
FROM dept;

```

## 4. Expressions Arithmétiques et Valeurs `NULL`

### Opérateurs Arithmétiques

Vous pouvez créer des expressions avec des données de type `NUMBER` et `DATE`.

| Opérateur | Description |  |
| --- | --- | --- |
| `+` | Addition |  |
| `-` | Soustraction |  |
| `*` | Multiplication |  |
| `/` | Division |  |

**Exemple :**

```sql
SELECT ename, sal, sal+300
FROM emp;

```

![[Pasted image 20260925234525.png|413]]

> [!abstract] Règle de Priorité (PEMDAS)
> 1. La multiplication (`*`) et la division (`/`) ont la priorité.
> 
> 
> 2. L'addition (`+`) et la soustraction (`-`) viennent ensuite.
> 
> 
> 3. À niveau égal, évaluation de **gauche à droite**.
> 
> 
> 4. Les **parenthèses `()**` forcent la priorité (ex: `12 * (sal + 100)`).
> 
> 
> 
> 

### Le Problème de la Valeur `NULL`

> [!warning] Comportement de `NULL`
> * `NULL` représente une valeur **non disponible, non affectée ou inconnue**.
> 
> 
> * `NULL` n'est **PAS** égal à zéro ($0$) ou à un espace vide (" ").
> 
> 
> * **Impact sur le calcul :** Toute expression arithmétique contenant une valeur `NULL` est évaluée à `NULL`.
> 
> 
>

## 5. Formatage de la Sortie : Alias, Concaténation et Littéraux

### L'Alias de Colonne

Permet de renommer temporairement l'en-tête de la colonne dans le résultat de la requête (très utile pour les colonnes calculées).

* Suit immédiatement le nom de la colonne (le mot-clé `AS` est optionnel).


* **Doit être entre guillemets doubles (`""`)** s'il contient des espaces ou des caractères spéciaux.



```sql
SELECT ename AS name, sal salary
FROM emp;

SELECT ename "Name", sal*12 "Annual Salary"
FROM emp;

```

![[Pasted image 20260925234625.png]]
### L'Opérateur de Concaténation

Permet de fusionner plusieurs colonnes ou chaînes de caractères en une seule colonne de résultat (type caractère).

* Opérateur standard : `||` (deux barres verticales).


* Fonction alternative (selon SGBD) : `CONCAT(col1, col2)`.



```sql
SELECT ename || job AS "Employees"
FROM emp;

SELECT CONCAT(ename, job) AS "Employees"
FROM emp;

```

![[Pasted image 20260925234639.png]]

### Chaînes de Caractères Littérales

Un littéral est un caractère, un nombre ou une expression textuelle inséré(e) manuellement dans la clause `SELECT`. Il sera répété sur chaque ligne du résultat. **Utilisez des guillemets simples (`' '`) pour les chaînes littérales.**

```sql
SELECT ename || ' is a ' || job AS "Employee Details"
FROM emp;

```

*(Résultat : `KING is a PRESIDENT`)*

## 6. Traitement des Doublons

Par défaut, une requête SQL ramène toutes les lignes qui valident la condition, **y compris les doublons** (lignes identiques).

> [!abstract] Le mot-clé `DISTINCT`
> Pour éliminer les doublons et n'afficher que les valeurs uniques, ajoutez le mot-clé `DISTINCT` juste après `SELECT`.
> 
> 

```sql
-- Affiche des doublons (ex: 10, 30, 10, 20...)
SELECT deptno
FROM emp;

-- Affiche des valeurs uniques (10, 20, 30)
SELECT DISTINCT deptno
FROM emp;

```
