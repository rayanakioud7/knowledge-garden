# Recursion Fundamentals & Examples

> [!info] Definitions & Properties
> *Recursion* is a technique in which a function calls itself during its execution. A recursive algorithm requires one or more base cases (conditions evaluated nonrecursively) and one or more recursive cases (steps that reduce progress toward a base case). An activation record (or frame) stores the function's namespace, local variables, and current instruction pointer during invocation.

---

## 1. The Factorial Function

The factorial function $n!$ represents the number of permutations of $n$ distinct elements. It is formally defined for any integer $n \ge 0$ as:

$$n! = \begin{cases} 1 & \text{if } n = 0 \\ n \cdot (n - 1)! & \text{if } n \ge 1 \end{cases}$$

| Component          | Condition | Behavior                                                                               |
| ------------------ | --------- | -------------------------------------------------------------------------------------- |
| **Base Case**      | $n = 0$   | Returns $1$ directly without further recursive calls.                                  |
| **Recursive Case** | $n \ge 1$ | Reduces the subproblem size to $n - 1$ and computes $n \cdot \text{factorial}(n - 1)$. |

```python
def factorial(n):
    """Return the factorial of a nonnegative integer."""
    if n == 0:
        return 1
    else:
        return n * factorial(n - 1)

```

### Function Execution via the Call Stack

Each call creates an activation record in memory. Calling a nested invocation suspends the caller until the callee returns its value.

| Stack Stage             | Active Activation Records                                                                | Call Stack State                                                |
| ----------------------- | ---------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| **Descent (Unwinding)** | `factorial(4)` $\to$ `factorial(3)` $\to$ $\dots$ $\to$ `factorial(0)`                   | Frames accumulate; each caller waits for its subproblem result. |
| **Base Evaluation**     | `factorial(0)`                                                                           | Returns $1$ without generating additional frames.               |
| **Ascent (Winding)**    | Resolves arithmetic: $1 \cdot 1 = 1$, $2 \cdot 1 = 2$, $3 \cdot 2 = 6$, $4 \cdot 6 = 24$ | Activation frames are popped in reverse order (LIFO).           |

## 2. Drawing an English Ruler

The markings of an English ruler exhibit a self-similar fractal structure. For each inch, a major tick line is drawn. Between whole inches, minor ticks are placed at intervals of $1/2$ inch, $1/4$ inch, and smaller powers of two.

> [!NOTE] Figure 4.2
> ![[Pasted image 20260907145447.png|center]]

### Interval Decomposition Logic

An interval with a central tick length $L \ge 1$ decomposes into three consecutive steps:

1. Draw top interval of central tick length $L - 1$.
2. Draw single central tick line of length $L$.
3. Draw bottom interval of central tick length $L - 1$.

```python
def draw_line(tick_length, tick_label=''):
    """Draw one line with given tick length (followed by optional label)."""
    line = '-' * tick_length
    if tick_label:
        line += ' ' + tick_label
    print(line)

def draw_interval(center_length):
    """Draw tick interval based upon a central tick length."""
    if center_length > 0:                   # stop when length drops to 0
        draw_interval(center_length - 1)    # recursively draw top ticks
        draw_line(center_length)            # draw center tick
        draw_interval(center_length - 1)    # recursively draw bottom ticks

def draw_ruler(num_inches, major_length):
    """Draw English ruler with given number of inches, major tick length."""
    draw_line(major_length, '0')            # draw inch 0 line
    for j in range(1, 1 + num_inches):
        draw_interval(major_length - 1)     # draw interior ticks for inch
        draw_line(major_length, str(j))     # draw inch j line and label

```

## 3. Binary Search

Binary search locates a target value within a sorted, indexable sequence of $n$ elements in $O(\log n)$ time, compared to $O(n)$ time for sequential search.

> [!NOTE] Figure 4.4
> ![[Pasted image 20260907145536.png|center]]

### Candidate Interval Partitioning

The candidate range is defined by two indices, $\text{low}$ and $\text{high}$. The midpoint index is computed as:

$$\text{mid} = \lfloor (\text{low} + \text{high}) / 2 \rfloor$$

| Case | Condition | Search Decision |
| --- | --- | --- |
| **Termination (Unsuccessful)** | $\text{low} > \text{high}$ | Range is empty; returns `False`. |
| **Termination (Successful)** | $\text{target} == \text{data}[\text{mid}]$ | Value located; returns `True`. |
| **Recur Left** | $\text{target} < \text{data}[\text{mid}]$ | Restrict search interval to $[\text{low}, \text{mid} - 1]$. |
| **Recur Right** | $\text{target} > \text{data}[\text{mid}]$ | Restrict search interval to $[\text{mid} + 1, \text{high}]$. |

```python
def binary_search(data, target, low, high):
    """Return True if target is found in indicated portion of a Python list.

    The search only considers the portion from data[low] to data[high] inclusive.
    """
    if low > high:
        return False                        # interval is empty; no match
    else:
        mid = (low + high) // 2
        if target == data[mid]:
            return True                     # found a match
        elif target < data[mid]:
            return binary_search(data, target, low, mid - 1)
        else:
            return binary_search(data, target, mid + 1, high)

```

## 4. File Systems & Cumulative Disk Usage

File systems have a recursive hierarchy where directories can contain files and sub-directories nested to arbitrary depth.

> [!NOTE] Figure 4.7
> ![[Pasted image 20260907145625.png|center]]

### Disk Space Calculation Rule

The cumulative disk space for entry $P$ equals its immediate disk usage plus the cumulative space of all nested child entries:

$$\text{cumulative\_space}(P) = \text{immediate\_space}(P) + \sum_{C \in \text{children}(P)} \text{cumulative\_space}(C)$$

### Python `os` Module Methods

| Method                         | Return Type | Description                                                                |
| ------------------------------ | ----------- | -------------------------------------------------------------------------- |
| `os.path.getsize(path)`        | `int`       | Returns the immediate disk usage of the file or directory in bytes.        |
| `os.path.isdir(path)`          | `bool`      | Evaluates to `True` if the path designates a directory; `False` otherwise. |
| `os.listdir(path)`             | `list[str]` | Returns entry names contained within the target directory.                 |
| `os.path.join(path, filename)` | `str`       | Joins path components using the operating system directory separator.      |

```python
import os

def disk_usage(path):
    """Return the number of bytes used by a file/folder and any descendants."""
    total = os.path.getsize(path)                  # account for direct usage
    if os.path.isdir(path):                        # if this is a directory
        for filename in os.listdir(path):          # then for each child:
            childpath = os.path.join(path, filename)
            total += disk_usage(childpath)         # add child's usage to total

    print('{0:<7}'.format(total), path)            # descriptive output
    return total

```
