# Array Applications & Insertion Sort

> [!info] Definitions & Properties Array-based 
> sequences support practical storage, sorting, and transformation tasks. Managing ordered collections with fixed capacity requires shifting elements during insertion, a mechanic shared by both high-score boards and insertion sort. Cryptographic substitution leverages character-to-index conversions and modulo arithmetic over contiguous arrays.
> 
>   

## 1. Storing High Scores (Scoreboard Application)

Maintaining a ranked list of game scores illustrates fixed-capacity array management.

### The GameEntry Class

The `GameEntry` class encapsulates a player's name and score.

```python
class GameEntry:
    """Represents one entry of a list of high scores."""

    def __init__(self, name, score):
        self._name = name
        self._score = score

    def get_name(self):
        return self._name

    def get_score(self):
        return self._score

    def __str__(self):
        return '({0}, {1})'.format(self._name, self._score)  # e.g., '(Bob, 98)'
```

### The Scoreboard Class

A `Scoreboard` maintains entries in non-increasing order up to a fixed maximum capacity.

```python
class Scoreboard:
    """Fixed-length sequence of high scores in nondecreasing order."""

    def __init__(self, capacity=10):
        """Initialize scoreboard with given maximum capacity.

        All entries are initially None.
        """
        self._board = [None] * capacity        # reserve space for future scores
        self._n = 0                            # number of actual entries

    def __getitem__(self, k):
        """Return entry at index k."""
        return self._board[k]

    def __str__(self):
        """Return string representation of the high score list."""
        return '\n'.join(str(self._board[j]) for j in range(self._n))

    def add(self, entry):
        """Consider adding entry to high scores."""
        score = entry.get_score()

        # Does new entry qualify as a high score?
        # Answer is yes if board not full or score is higher than last entry
        good = self._n < len(self._board) or score > self._board[-1].get_score()

        if good:
            if self._n < len(self._board):      # no score drops from list
                self._n += 1                   # so overall number increases

            # shift lower scores rightward to make room for new entry
            j = self._n - 1
            while j > 0 and self._board[j - 1].get_score() < score:
                self._board[j] = self._board[j - 1]  # shift entry from j-1 to j
                j -= 1                               # and decrement j
            self._board[j] = entry                   # when done, add new entry
```

### Insertion and Shifting Mechanics

- **Qualification**: A score qualifies if the board is not full ($n < \text{capacity}$) or if it exceeds the lowest recorded score ($score > \text{board}[-1].\text{get\_score()}$).
    
    
- **Rightward Shifting**: Lower scores shift rightward by one position starting from the tail to avoid overwriting elements.
    
      
- **Worst-Case Cost**: When an entry becomes the highest score, all $n$ existing entries shift rightward, taking $O(n)$ time.
    
      

## 2. Sorting a Sequence: Insertion-Sort

Insertion-sort iteratively places each element into its proper position within an already sorted prefix.

  

### High-Level Algorithm Trace

1. Consider the first element $A[0]$ sorted.
    
    
2. For each element $A[k]$ from $k = 1$ to $n - 1$, cache $A[k]$ in variable `cur`.
    
      
3. Shift elements greater than `cur` in subarray $A[0 \dots k-1]$ rightward by one cell.
    
      
4. Insert `cur` into the resulting vacancy.
    
      

```python
def insertion_sort(A):
    """Sort list of comparable elements into nondecreasing order."""
    for k in range(1, len(A)):         # from 1 to n-1
        cur = A[k]                     # current element to be inserted
        j = k                          # find correct index j for current
        while j > 0 and A[j - 1] > cur: # element A[j-1] must be after current
            A[j] = A[j - 1]
            j -= 1
        A[j] = cur                     # cur is now in the right place
```

### Complexity Analysis

The running time depends on the initial order of elements:

  

- **Worst-Case**: If the array is in reverse order, each step $k$ shifts all $k$ preceding elements:
    
      
    

$$\sum_{k=1}^{n-1} k = \frac{(n-1)n}{2} \implies O(n^2)$$

- **Best-Case**: If the array is already sorted, the `while` loop condition `A[j - 1] > cur` evaluates to `False` immediately on every pass. The algorithm performs no element shifts and completes in $O(n)$ time.
    
    
## 3. Simple Cryptography: The Caesar Cipher

The Caesar cipher is an ancient substitution cipher that shifts each uppercase Latin letter by a fixed rotation value $r$.

### Modular Arithmetic Equations

Let index $i \in \{0, 1, \dots, 25\}$ represent letters $\text{A}$ through $\text{Z}$.

$$\text{Encryption: } C = (i + r) \pmod{26}$$
$$\text{Decryption: } P = (i - r) \pmod{26}$$

### Character-to-Index Conversion

Python uses Unicode code points to compute array offsets:
  

- `ord(c)` returns the integer code point for character `c`.
      
    
- `chr(j)` returns the character for code point `j`.
      
    
- Letter index: $j = \text{ord}(c) - \text{ord}(\text{'A'})$.

```python
class CaesarCipher:
    """Class for doing encryption and decryption using a Caesar cipher."""

    def __init__(self, shift):
        """Construct Caesar cipher using given integer shift for rotation."""
        encoder = [None] * 26                  # temp array for encryption
        decoder = [None] * 26                  # temp array for decryption
        for k in range(26):
            encoder[k] = chr((k + shift) % 26 + ord('A'))
            decoder[k] = chr((k - shift) % 26 + ord('A'))
        self._forward = ''.join(encoder)       # will store as string
        self._backward = ''.join(decoder)      # since fixed

    def encrypt(self, message):
        """Return string representing encrypted message."""
        return self._transform(message, self._forward)

    def decrypt(self, secret):
        """Return decrypted message given encrypted secret."""
        return self._transform(secret, self._backward)

    def _transform(self, original, code):
        """Utility to perform transformation based on given code string."""
        msg = list(original)
        for k in range(len(msg)):
            if msg[k].isupper():
                j = ord(msg[k]) - ord('A')     # index from 0 to 25
                msg[k] = code[j]               # replace this character
        return ''.join(msg)
```
