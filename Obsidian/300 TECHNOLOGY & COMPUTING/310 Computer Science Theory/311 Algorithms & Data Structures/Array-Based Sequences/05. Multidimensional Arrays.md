> [!definition] Multidimensional Data & Matrices
> A two-dimensional array is often called a **matrix**. It is accessed using two indices, $i$ (row) and $j$ (column), which are traditionally **zero-indexed** in computer science.
> $$M = \begin{bmatrix} data[0][0] & \dots & data[0][c-1] \\ \vdots & \ddots & \vdots \\ data[r-1][0] & \dots & data[r-1][c-1] \end{bmatrix}$$

In Python, the most common representation for a 2D array is a **list of lists**.

## Constructing a Multidimensional List (The Aliasing Trap)

> [!danger] CRITICAL ENGINEERING CONCEPT: Reference Aliasing
> When creating a list of lists, you must ensure each row is an **independent instance**. If you use the multiplication operator `*` on a list of lists, you create multiple references to the *same* underlying list object. Modifying one row will modify all rows.

### Comparison of Initialization Methods

| Method                 | Code Syntax                          | Result                                                                           | Verdict               |
| :--------------------- | :----------------------------------- | :------------------------------------------------------------------------------- | :-------------------- |
| **1D Flattened**       | `data = ([0] * c) * r`               | Creates a single 1D list of length $r \cdot c$.                                  | ❌ **Wrong Structure** |
| **Aliasing (Shallow)** | `data = [[0] * c] * r`               | Creates $r$ references to the *same* inner list. `data[0] is data[1]` is `True`. | ❌ **Dangerous Bug**   |
| **List Comprehension** | `data = [[0] * c for j in range(r)]` | Creates $r$ **distinct, independent** secondary lists.                           | ✅ **Correct**         |

![[Pasted image 20261001194856.png]]

![[Pasted image 20261001194908.png]]

> [!tip] The Rule for 2D Lists
> Always use **list comprehension** to initialize multidimensional lists to guarantee independent memory allocation for each row.

 ```python
 # Correct way to initialize an r x c matrix of zeros
 data = [[0] * c for j in range(r)]
 ```

## Two-Dimensional Arrays and Positional Games

Positional games (like Tic-Tac-Toe, Chess, Checkers) naturally map to 2D arrays. 

### Tic-Tac-Toe Implementation

**Representation:** A $3 \times 3$ list of lists of characters.
*   `'X'` or `'O'`: Player moves.
*   `' '`: Empty space.

```python
# Internal representation of a board state
board = [
    ['O', 'X', 'O'], 
    [' ', 'X', ' '], 
    [' ', 'O', 'X']
]
```

### Complete Python Class Implementation

> [!note] Design Pattern
> This class manages state and rules, but **does not** contain AI strategy. It separates game logic from game playing.

```python
class TicTacToe:
    """Management of a Tic-Tac-Toe game (does not do strategy)."""

    def __init__(self):
        """Start a new game."""
        self._board = [[' '] * 3 for j in range(3)] # Independent rows!
        self._player = 'X'

    def mark(self, i, j):
        """Put an X or O mark at position (i,j) for next player's turn."""
        if not (0 <= i <= 2 and 0 <= j <= 2):
            raise ValueError('Invalid board position')
        if self._board[i][j] != ' ':
            raise ValueError('Board position occupied')
        if self.winner() is not None:
            raise ValueError('Game is already complete')
        
        self._board[i][j] = self._player
        if self._player == 'X':
            self._player = 'O'
        else:
            self._player = 'X'

    def _is_win(self, mark):
        """Check whether the board configuration is a win for the given player."""
        board = self._board # local variable for shorthand
        return (
            mark == board[0][0] == board[0][1] == board[0][2] or  # row 0
            mark == board[1][0] == board[1][1] == board[1][2] or  # row 1
            mark == board[2][0] == board[2][1] == board[2][2] or  # row 2
            mark == board[0][0] == board[1][0] == board[2][0] or  # col 0
            mark == board[0][1] == board[1][1] == board[2][1] or  # col 1
            mark == board[0][2] == board[1][2] == board[2][2] or  # col 2
            mark == board[0][0] == board[1][1] == board[2][2] or  # diag
            mark == board[0][2] == board[1][1] == board[2][0]     # rev diag
        )

    def winner(self):
        """Return mark of winning player, or None to indicate a tie."""
        for mark in 'XO':
            if self._is_win(mark):
                return mark
        return None

    def __str__(self):
        """Return string representation of current game board."""
        rows = ['|'.join(self._board[r]) for r in range(3)]
        return '\n-----\n'.join(rows)
```

### Usage Example

```python
game = TicTacToe()

# X moves
game.mark(1, 1);  game.mark(0, 2)  # O moves
game.mark(2, 2);  game.mark(0, 0)
game.mark(0, 1);  game.mark(2, 1)
game.mark(1, 2);  game.mark(1, 0)
game.mark(2, 0)

print(game)
winner = game.winner()
if winner is None:
    print('Tie')
else:
    print(winner, 'wins!')
```
