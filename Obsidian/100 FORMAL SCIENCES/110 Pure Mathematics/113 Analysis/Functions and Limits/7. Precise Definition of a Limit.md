## The Precise Definition of a Limit

The intuitive definitions of limits (e.g., "$x$ is close to $2$") are mathematically vague. To prove limit statements rigorously, we use the precise metric formulation known as the **$\varepsilon$-$\delta$ (epsilon-delta) definition**.

---

### Foundational Formal Definition

> [!info] Definition: Rigorous Limit ($\varepsilon$-$\delta$)
> Let $f$ be a function defined on some open interval that contains the number $a$, except possibly at $a$ itself. We say that the **limit of $f(x)$ as $x$ approaches $a$ is $L$**, written as:
> $$\lim_{x \to a} f(x) = L$$
> if for every error tolerance $\varepsilon > 0$, there exists a corresponding distance number $\delta > 0$ such that:
> $$\text{if } 0 < |x - a| < \delta \quad \text{then} \quad |f(x) - L| < \varepsilon$$

#### Meaning of the Absolute Value Inequalities:
* **$|f(x) - L| < \varepsilon$:** The distance between $f(x)$ and $L$ is less than $\varepsilon$. This can be rewritten as the interval:
  $$L - \varepsilon < f(x) < L + \varepsilon$$
* **$0 < |x - a| < \delta$:** The distance between $x$ and $a$ is less than $\delta$. The constraint $0 < |x - a|$ explicitly means $x \neq a$, enforcing that the value *at* $a$ does not matter. This matches the input interval:
  $$a - \delta < x < a + \delta \quad (x \neq a)$$

1. **Interval Mapping (Arrow Diagrams):** For any small target interval $(L - \varepsilon, L + \varepsilon)$ surrounding $L$, we can find a neighborhood $(a - \delta, a + \delta)$ around $a$ such that $f$ maps all points in this domain (except possibly $a$) into the target interval.

> [!example] Example 1: Finding $\delta$ Graphically from a Curve
> Use a graph to find a number $\delta$ such that:
> $$\text{if } |x - 1| < \delta \quad \text{then} \quad |(x^3 - 5x + 6) - 2| < 0.2$$
> Here, $f(x) = x^3 - 5x + 6$, $a = 1$, $L = 2$, and $\varepsilon = 0.2$.
> 
> **Step-by-Step Solution:**
> 1. **Establish Horizontal Bounds ($|f(x) - 2| < 0.2$):**
>    $$2 - 0.2 < x^3 - 5x + 6 < 2 + 0.2 \implies 1.8 < x^3 - 5x + 6 < 2.2$$
> 2. **Determine Intersection Points:**
>    Using a graphing utility, find where the curve intersects the target lines $y = 1.8$ and $y = 2.2$ near $(1,2)$:
>    - Intersection with $y = 2.2 \implies x \approx 0.911$
>    - Intersection with $y = 1.8 \implies x \approx 1.124$
> 3. **Calculate Interval Distances from $a=1$:**
>    - Distance to left endpoint: $1 - 0.911 = 0.089$
>    - Distance to right endpoint: $1.124 - 1 = 0.124$
> 4. **Choose $\delta$ safely:** To ensure *both* sides stay within bounds, select the **smaller** of the two distances, rounded down conservatively:
>    $$\delta = 0.08$$

### Structure of an Epsilon-Delta Proof

Proving a limit using the precise definition is a two-stage process:
1. **Preliminary Analysis:** Guess a value for $\delta$ by manipulating the $\varepsilon$ inequality to isolate $|x - a|$.
2. **Formal Proof:** Demonstrate conclusively that the chosen $\delta$ satisfies the conditional statement.

---

> [!example] Example 2: Rigorous Linear Proof
> Prove that $\lim_{x \to 3} (4x - 5) = 7$.
> 
> **Step 1: Preliminary Analysis (Finding $\delta$)**
> Let $\varepsilon > 0$. We want to find a number $\delta > 0$ such that:
> $$\text{if } 0 < |x - 3| < \delta \quad \text{then} \quad |(4x - 5) - 7| < \varepsilon$$
> Simplify the target epsilon expression:
> $$|(4x - 5) - 7| = |4x - 12| = |4(x - 3)| = 4|x - 3|$$
> We want:
> $$4|x - 3| < \varepsilon \implies |x - 3| < \frac{\varepsilon}{4}$$
> This suggests we should choose **$\delta = \frac{\varepsilon}{4}$**.
> 
> **Step 2: The Formal Proof (Showing this $\delta$ works)**
> Given $\varepsilon > 0$, choose $\delta = \frac{\varepsilon}{4}$.
> If $0 < |x - 3| < \delta$, then:
> $$|(4x - 5) - 7| = |4x - 12| = 4|x - 3| < 4\delta = 4\left(\frac{\varepsilon}{4}\right) = \varepsilon$$
> Thus, by the definition of a limit, $\lim_{x \to 3} (4x - 5) = 7$.

## Precise Definitions of One-Sided Limits

The directional limit behaviors can be rigorously formulated by restricting the input intervals to the left or right halves of the standard two-sided window.

### Left-Hand Limit
> [!info] Precise Left-Hand Definition
> $$\lim_{x \to a^-} f(x) = L$$
> if for every $\varepsilon > 0$ there is a corresponding $\delta > 0$ such that:
> $$\text{if } a - \delta < x < a \quad \text{then} \quad |f(x) - L| < \varepsilon$$
> Here, $x$ is restricted strictly to the left half of the neighborhood: $(a - \delta, a)$.

### Right-Hand Limit
> [!info] Precise Right-Hand Definition
> $$\lim_{x \to a^+} f(x) = L$$
> if for every $\varepsilon > 0$ there is a corresponding $\delta > 0$ such that:
> $$\text{if } a < x < a + \delta \quad \text{then} \quad |f(x) - L| < \varepsilon$$
> Here, $x$ is restricted strictly to the right half of the neighborhood: $(a, a + \delta)$.

---

> [!example] Example 3: Proving a Right-Hand Radical Limit
> Use the precise right-hand limit definition to prove that $\lim_{x \to 0^+} \sqrt{x} = 0$.
> 
> **Step 1: Preliminary Analysis (Guessing $\delta$)**
> Let $\varepsilon > 0$. We need to find a $\delta > 0$ corresponding to $a = 0$ and $L = 0$ such that:
> $$\text{if } 0 < x < 0 + \delta \quad \text{then} \quad |\sqrt{x} - 0| < \varepsilon$$
> Simplify the target expressions:
> $$\text{if } 0 < x < \delta \quad \text{then} \quad \sqrt{x} < \varepsilon$$
> Squaring both sides of the target inequality $\sqrt{x} < \varepsilon$ isolates $x$:
> $$x < \varepsilon^2$$
> This structure suggests we should choose **$\delta = \varepsilon^2$**.
> 
> **Step 2: Formal Proof (Showing this $\delta$ works)**
> Given $\varepsilon > 0$, select $\delta = \varepsilon^2$.
> If $0 < x < \delta$, it follows that:
> $$\sqrt{x} < \sqrt{\delta} = \sqrt{\varepsilon^2} = \varepsilon \implies |\sqrt{x} - 0| < \varepsilon$$
> Thus, by the definition of a right-hand limit, $\lim_{x \to 0^+} \sqrt{x} = 0$.

## Analytical Proof of Limit Laws

While epsilon-delta proofs can become highly complex for complicated rational functions, they are essential for proving foundational properties like the **Limit Laws**.

> [!tip] The Triangle Inequality
> In precise analytical proofs, the absolute value triangle inequality is a vital tool for splitting compound errors:
> $$|a + b| \le |a| + |b|$$

### Rigorous Proof of the Sum Law
Prove that if $\lim_{x \to a} f(x) = L$ and $\lim_{x \to a} g(x) = M$, then $\lim_{x \to a} [f(x) + g(x)] = L + M$.

**Step-by-Step Proof Construction:**
1. **Analyze Target Error Expression:**
   We want to bring the total error $|(f(x) + g(x)) - (L + M)|$ below a chosen tolerance $\varepsilon$. Rearrange terms and apply the triangle inequality:
   $$|[f(x) - L] + [g(x) - M]| \le |f(x) - L| + |g(x) - M|$$
2. **Establish Half-Error Tolerances ($\varepsilon/2$):**
   - Since $\lim_{x \to a} f(x) = L$, for the error bound $\frac{\varepsilon}{2} > 0$ there exists a $\delta_1 > 0$ such that:
     $$\text{if } 0 < |x - a| < \delta_1 \quad \text{then} \quad |f(x) - L| < \frac{\varepsilon}{2}$$
   - Since $\lim_{x \to a} g(x) = M$, for the error bound $\frac{\varepsilon}{2} > 0$ there exists a $\delta_2 > 0$ such that:
     $$\text{if } 0 < |x - a| < \delta_2 \quad \text{then} \quad |g(x) - M| < \frac{\varepsilon}{2}$$
3. **Choose a Restrictive $\delta$:**
   Select $\delta = \min\{\delta_1, \delta_2\}$, matching the tighter of the two input windows.
   If $0 < |x - a| < \delta$, then both individual constraints hold simultaneously:
   $$|f(x) - L| < \frac{\varepsilon}{2} \quad \text{and} \quad |g(x) - M| < \frac{\varepsilon}{2}$$
4. **Sum the Total Bounds:**
   Combine the inequalities using the triangle inequality setup from step 1:
   $$|[f(x) + g(x)] - (L + M)| \le |f(x) - L| + |g(x) - M| < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon$$
   
Therefore, by the precise definition of a limit, $\lim_{x \to a} [f(x) + g(x)] = L + M$.

### Positive Infinite Limits

> [!info] Precise Definition: $\lim_{x \to a} f(x) = \infty$
> Let $f$ be a function defined on some open interval that contains the number $a$, except possibly at $a$ itself. Then the statement means that for every positive number $M$, there exists a corresponding positive number $\delta > 0$ such that:
> $$\text{if } 0 < |x - a| < \delta \quad \text{then} \quad f(x) > M$$

#### Geometric Significance
Given any horizontal threshold line $y = M$, we can find a vertical distance neighborhood $\delta > 0$ such that if we restrict $x$ to the open interval $(a - \delta, a + \delta)$ with $x \neq a$, the curve $y = f(x)$ will lie entirely **above** the line $y = M$. Choosing a larger value for $M$ typically requires finding a smaller corresponding value for $\delta$.

---

> [!example] Example 5: Proving an Infinite Limit Rigorously
> Use the precise definition to prove that $\lim_{x \to 0} \frac{1}{x^2} = \infty$.
> 
> **Step 1: Preliminary Analysis (Finding $\delta$)**
> Let $M$ be a given positive number. We want to find a number $\delta > 0$ such that:
> $$\text{if } 0 < |x| < \delta \quad \text{then} \quad \frac{1}{x^2} > M$$
> Manipulate the target inequality to isolate $|x|$:
> $$\frac{1}{x^2} > M \iff x^2 < \frac{1}{M} \iff |x| < \frac{1}{\sqrt{M}}$$
> This algebraic chain suggests choosing **$\delta = \frac{1}{\sqrt{M}}$**.
> 
> **Step 2: Formal Proof (Showing this $\delta$ works)**
> Given $M > 0$, choose $\delta = \frac{1}{\sqrt{M}}$.
> If $0 < |x| < \delta = \frac{1}{\sqrt{M}}$, then squaring both sides yields:
> $$x^2 < \frac{1}{M} \implies \frac{1}{x^2} > M$$
> Thus, by the precise definition of an infinite limit, $\lim_{x \to 0} \frac{1}{x^2} = \infty$.

### 2. Negative Infinite Limits

> [!info] Precise Definition: $\lim_{x \to a} f(x) = -\infty$
> Let $f$ be a function defined on some open interval that contains the number $a$, except possibly at $a$ itself. Then the statement means that for every negative number $N$, there exists a corresponding positive number $\delta > 0$ such that:
> $$\text{if } 0 < |x - a| < \delta \quad \text{then} \quad f(x) < N$$

#### Geometric Significance
Given any horizontal negative bound line $y = N$, we can isolate a vertical interval $(a - \delta, a + \delta)$ such that for all $x \neq a$ inside this strip, the curve $y = f(x)$ lies entirely **below** the line $y = N$.
