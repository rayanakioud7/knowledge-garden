## Four Ways to Represent a Function

> [!info] Definition of a Function
> A **function** $f$ is a rule that assigns to each element $x$ in a set $D$ exactly one element, called $f(x)$, in a set $E$.
> * **Domain ($D$):** The set of all possible input values.
> * **Range:** The set of all possible output values $f(x)$ as $x$ varies throughout the domain.
> * **Independent Variable:** A symbol representing arbitrary inputs in the domain (e.g., $x$).
> * **Dependent Variable:** A symbol representing outputs in the range (e.g., $y$).
> 
> ![[Pasted image 20260625140148.png|center]]

### Conceptual Models

* **Machine Diagram:** Input $x \to \text{Machine } f \to \text{Output } f(x)$.
* **Arrow Diagram:** Each arrow connects an element of $D$ to a unique element of $E$.
* **Graph:** The set of ordered pairs $\{(x, f(x)) \mid x \in D\}$. Geometrically, the domain is mapped along the $x$-axis and the range along the $y$-axis.

> * Domain: $\mathbb{R}$ | Range: $\mathbb{R}$

> 
> **(b) Quadratic:** $g(x) = x^2$
> * Domain: $\mathbb{R}$ | Range: $[0, \infty)$

## The Difference Quotient

> [!info] Definition
> The expression below represents the average rate of change of $f(x)$ from $x=a$ to $x=a+h$:
> 
> $$\frac{f(a + h) - f(a)}{h}$$
> 
> 

> [!example] Example 3: Evaluating a Difference Quotient
> For $f(x) = 2x^2 - 5x + 1$, evaluate the difference quotient when $h \neq 0$.
> **Step 1: Expand $f(a+h)$:**
> 
> $$f(a+h) = 2(a+h)^2 - 5(a+h) + 1 = 2a^2 + 4ah + 2h^2 - 5a - 5h + 1$$
> 
> 
> **Step 2: Substitute and simplify:**
> 
> $$\begin{aligned}
> \frac{f(a+h) - f(a)}{h} &= \frac{(2a^2 + 4ah + 2h^2 - 5a - 5h + 1) - (2a^2 - 5a + 1)}{h} \\
> &= \frac{4ah + 2h^2 - 5h}{h} \\
> &= 4a + 2h - 5
> \end{aligned}$$
> 
>

## Representations of Functions

Functions can be represented in four distinct ways:
* **Verbally:** By a description in words.
* **Numerically:** By a table of values (**tabular** function).
* **Visually:** By a graph.
* **Algebraically:** By an explicit mathematical formula.

> [!example] Example 5: Building an Algebraic Optimization Function
> A rectangular storage container with an open top has a volume of $10\text{ m}^3$. The base length is twice its width ($w$). Base material costs $\$10/\text{m}^2$; side material costs $\$6/\text{m}^2$. Express total cost $C$ as a function of $w$.
> 
> ![[Pasted image 20260625142811.png|center]]
> 
> **Step-by-Step Solution:**
> 1. **Assign variables and find base area:**
>    - Width $= w$, Length $= 2w$, Height $= h$
>    - $\text{Base Area} = w(2w) = 2w^2$
> 2. **Calculate area of the sides:**
>    - Two sides with area $wh$, two sides with area $2wh$.
> 3. **Set up the cost equation:**
>    $$C = 10(2w^2) + 6[2(wh) + 2(2wh)] = 20w^2 + 36wh$$
> 4. **Eliminate $h$ using the Volume constraint ($V = 10$):**
>    $$V = w(2w)h = 10 \implies 2w^2h = 10 \implies h = \frac{5}{w^2}$$
> 5. **Substitute $h$ back into the cost equation:**
>    $$C(w) = 20w^2 + 36w\left(\frac{5}{w^2}\right) = 20w^2 + \frac{180}{w}, \quad w > 0$$

## Domain Conventions

> [!warning] Domain Convention Rule
> If a function is given by a formula and the domain is not stated explicitly, the domain is assumed to be the **set of all real numbers for which the algebraic formula makes mathematical sense** (i.e., avoids division by zero or taking even roots of negative numbers).

---

> [!example] Example 6: Finding Analytic Domains
> Find the domain of each function:
> 
> **(a)** $f(x) = \sqrt{x + 2}$
> - **Constraint:** Radicand must be nonnegative for real values.
>   $$x + 2 \ge 0 \implies x \ge -2$$
> - **Domain:** $[-2, \infty)$
> 
> **(b)** $g(x) = \frac{1}{x^2 - x}$
> - **Constraint:** Denominator cannot equal zero. Factor the denominator:
>   $$x^2 - x = x(x - 1) \neq 0 \implies x \neq 0 \text{ and } x \neq 1$$
> - **Domain Set:** $\{x \mid x \neq 0, x \neq 1\}$
> - **Interval Notation:** $(-\infty, 0) \cup (0, 1) \cup (1, \infty)$

## The Vertical Line Test

> [!info] The Vertical Line Test
> A curve in the $xy$-plane is the graph of a function of $x$ if and only if no vertical line intersects the curve more than once.
> - **Single Intersection:** If a line $x = a$ intersects a curve exactly once at $(a, b)$, then $f(a) = b$ uniquely defines a single functional value.
> - **Multiple Intersections:** If a line $x = a$ intersects a curve multiple times (e.g., at $(a, b)$ and $(a, c)$), the curve **cannot** represent a function because a function cannot assign two different output values to a single input $a$.

![[Pasted image 20260625144328.png|center]]

---

> [!example] Example 14: Analyzing $x = y^2 - 2$
> Consider the parabola $x = y^2 - 2$:
> - **As a function of $x$:** It fails the Vertical Line Test because a vertical line can intersect it twice.
> - **Splitting into algebraic functions:** The equation $x = y^2 - 2 \implies y^2 = x + 2$ can be split into two explicit functions of $x$:
>   - **Upper half:** $f(x) = \sqrt{x + 2}$
>   - **Lower half:** $g(x) = -\sqrt{x + 2}$
> - **As a function of $y$:** If we reverse the independent and dependent variables ($x = h(y) = y^2 - 2$), it defines a valid function of $y$.

## Piecewise Defined Functions

> [!info] Definition
> **Piecewise defined functions** are functions that are defined by different algebraic formulas on different parts of their domain.

---

> [!example] Example 7: Evaluating and Graphing Piecewise Functions
> A function $f$ is defined by:
> $$f(x) = \begin{cases} 1 - x & \text{if } x \le -1 \\ x^2 & \text{if } x > -1 \end{cases}$$
> 
> **Evaluation:**
> - $f(-2) = 1 - (-2) = 3 \quad (\text{since } -2 \le -1)$
> - $f(-1) = 1 - (-1) = 2 \quad (\text{since } -1 \le -1)$
> - $f(0) = 0^2 = 0 \quad (\text{since } 0 > -1)$
> 
> **Graphing Properties:**
> - To the left of $x = -1$, the graph is a line with slope $-1$ and includes the solid endpoint point $(-1, 2)$.
> - To the right of $x = -1$, the graph is a parabola with an open dot placeholder at $(-1, 1)$, indicating exclusion.

### The Absolute Value Function

The **absolute value** of a number $a$, denoted by $|a|$, is the distance from $a$ to $0$ on the real number line ($|a| \ge 0$).

> [!info] Piecewise Definition of Absolute Value
> $$|x| = \begin{cases} x & \text{if } x \ge 0 \\ -x & \text{if } x < 0 \end{cases}$$

![[Pasted image 20260625144538.png|center]]

---

> [!example] Example 9: Finding a Formula from a Piecewise Graph
> Find a formula for the function $f$ pictured below:
> 
> **Step-by-Step Analysis:**
> 1. **Interval $0 \le x \le 1$:** Line passes through $(0,0)$ and $(1,1)$.
>    $$m = 1, \; b = 0 \implies f(x) = x$$
> 2. **Interval $1 < x \le 2$:** Line passes through $(1,1)$ and $(2,0)$.
>    $$m = \frac{0 - 1}{2 - 1} = -1 \implies y - 0 = -1(x - 2) \implies f(x) = 2 - x$$
> 3. **Interval $x > 2$:** The graph coincides with the $x$-axis.
>    $$f(x) = 0$$
> 
> **Unified Formula:**
> $$f(x) = \begin{cases} x & \text{if } 0 \le x \le 1 \\ 2 - x & \text{if } 1 < x \le 2 \\ 0 & \text{if } x > 2 \end{cases}$$

## Symmetry

### Even Functions
> [!info] Definition & Geometric Significance
> A function $f$ is an **even function** if it satisfies the following relation for every number $x$ in its domain:
> $$f(-x) = f(x)$$
> Geometrically, the graph of an even function is **symmetric with respect to the $y$-axis**. Reflecting the graph portion for $x \ge 0$ across the $y$-axis yields the complete curve.
> 
> *Example:* $f(x) = x^2$ is even because $f(-x) = (-x)^2 = x^2 = f(x)$.

![[Pasted image 20260625144825.png|center]]
### Odd Functions
> [!info] Definition & Geometric Significance
> A function $f$ is an **odd function** if it satisfies the following relation for every number $x$ in its domain:
> $$f(-x) = -f(x)$$
> Geometrically, the graph of an odd function is **symmetric about the origin**. The entire graph can be obtained by rotating the portion for $x \ge 0$ by $180^\circ$ around the origin.
> 
> *Example:* $f(x) = x^3$ is odd because $f(-x) = (-x)^3 = -x^3 = -f(x)$.

![[Pasted image 20260625144855.png|center]]

---

> [!example] Example 11: Classifying Symmetry Analytic Tests
> Determine whether each function is even, odd, or neither:
> 
> **(a)** $f(x) = x^5 + x$
> - Test: $f(-x) = (-x)^5 + (-x) = -x^5 - x = -(x^5 + x) = -f(x)$
> - **Result:** **Odd function** (Origin symmetry)
> 
> **(b)** $g(x) = 1 - x^4$
> - Test: $g(-x) = 1 - (-x)^4 = 1 - x^4 = g(x)$
> - **Result:** **Even function** ($y$-axis symmetry)
> 
> **(c)** $h(x) = 2x - x^2$
> - Test: $h(-x) = 2(-x) - (-x)^2 = -2x - x^2$
> - Check: $h(-x) \neq h(x)$ and $h(-x) \neq -h(x)$
> - **Result:** **Neither even nor odd**

## Increasing and Decreasing Functions

Let $x_1$ and $x_2$ be any two distinct values inside an interval $I$ such that $x_1 < x_2$.

> [!info] Monotonic Properties
> * A function $f$ is **increasing** on an interval $I$ if:
>   $$f(x_1) < f(x_2) \quad \text{whenever} \quad x_1 < x_2 \text{ in } I$$
> * A function $f$ is **decreasing** on an interval $I$ if:
>   $$f(x_1) > f(x_2) \quad \text{whenever} \quad x_1 < x_2 \text{ in } I$$

![[Pasted image 20260625144942.png|center]]

---

> [!example] Example Case: $f(x) = x^2$
> Looking at the monotonic intervals of the standard parabola:
> - On the interval $(-\infty, 0]$, as you move left-to-right, the heights decrease $\implies$ **Decreasing**.
> - On the interval $[0, \infty)$, as you move left-to-right, the heights increase $\implies$ **Increasing**.
