## 7.7 Approximate Integration

### 1. Endpoint and Midpoint Approximations

> [!info] Left and Right Endpoint Approximations
> When evaluating a definite integral $\int_a^b f(x) \, dx$, dividing the interval $[a,b]$ into $n$ subintervals of equal length $\Delta x = (b - a)/n$ allows us to approximate the integral using Riemann sums.
> *   **Left Endpoint Approximation:** Evaluates the function at the left endpoint of each subinterval ($x_i^* = x_{i-1}$).
>     $$ \boxed{ \int_a^b f(x) \, dx \approx L_n = \sum_{i=1}^n f(x_{i-1}) \Delta x } $$
>     
>    ![[Pasted image 20260906203843.png|center]]
>    
> *   **Right Endpoint Approximation:** Evaluates the function at the right endpoint of each subinterval ($x_i^* = x_i$).
>     $$ \boxed{ \int_a^b f(x) \, dx \approx R_n = \sum_{i=1}^n f(x_i) \Delta x } $$
>     
>    ![[Pasted image 20260906203814.png|center]]

> [!info] Midpoint Rule
> **The Midpoint Rule** uses the midpoint $\bar{x}_i$ of each subinterval $[x_{i-1}, x_i]$ to evaluate the function, which generally provides a better approximation than the left or right endpoints.
> $$ \boxed{ \int_a^b f(x) \, dx \approx M_n = \Delta x [f(\bar{x}_1) + f(\bar{x}_2) + \cdots + f(\bar{x}_n)] } $$
> where $\Delta x = \frac{b - a}{n}$ and $\bar{x}_i = \frac{1}{2}(x_{i-1} + x_i) = \text{midpoint of } [x_{i-1}, x_i]$.

### 2. Trapezoidal Rule

> [!info] Trapezoidal Rule
> **The Trapezoidal Rule** results from averaging the left and right endpoint approximations, geometrically corresponding to approximating the area under the curve using trapezoids.
> $$ \boxed{ \int_a^b f(x) \, dx \approx T_n = \frac{\Delta x}{2} [f(x_0) + 2f(x_1) + 2f(x_2) + \cdots + 2f(x_{n-1}) + f(x_n)] } $$
> where $\Delta x = \frac{(b - a)}{n}$ and $x_i = a + i \Delta x$.

![[Pasted image 20260906203917.png|411]]

> [!example] Example 1: Applying Trapezoidal and Midpoint Rules
> **Problem:** Use (a) the Trapezoidal Rule and (b) the Midpoint Rule with $n = 5$ to approximate the integral $\int_1^2 (1/x) \, dx$.
> 
> **Solution:**
> (a) With $n=5$, $a=1$, and $b=2$, we have $\Delta x = (2-1)/5 = 0.2$. The Trapezoidal Rule gives:
> $$ \begin{aligned} \int_1^2 \frac{1}{x} \, dx \approx T_5 &= \frac{0.2}{2} [f(1) + 2f(1.2) + 2f(1.4) + 2f(1.6) + 2f(1.8) + f(2)] \\ &= 0.1 \left( \frac{1}{1} + \frac{2}{1.2} + \frac{2}{1.4} + \frac{2}{1.6} + \frac{2}{1.8} + \frac{1}{2} \right) \\ &\approx 0.695635 \end{aligned} $$
> 
> (b) The midpoints of the five subintervals are $1.1, 1.3, 1.5, 1.7, \text{ and } 1.9$. The Midpoint Rule gives:
> $$ \begin{aligned} \int_1^2 \frac{1}{x} \, dx \approx M_5 &= \Delta x [f(1.1) + f(1.3) + f(1.5) + f(1.7) + f(1.9)] \\ &= \frac{1}{5} \left( \frac{1}{1.1} + \frac{1}{1.3} + \frac{1}{1.5} + \frac{1}{1.7} + \frac{1}{1.9} \right) \\ &\approx 0.691908 \end{aligned} $$

### 3. Error Bounds for Trapezoidal and Midpoint Rules

> [!info] Error Bounds for Trapezoidal and Midpoint Rules
> The error in using an approximation is defined as the amount that needs to be added to the approximation to make it exact (i.e., $\int_a^b f(x) \, dx = \text{approximation} + \text{error}$).
> Suppose $|f''(x)| \le K$ for $a \le x \le b$. If $E_T$ and $E_M$ are the errors in the Trapezoidal and Midpoint Rules, then:
> $$ \boxed{ |E_T| \le \frac{K(b - a)^3}{12n^2} } \quad \text{and} \quad \boxed{ |E_M| \le \frac{K(b - a)^3}{24n^2} } $$
> *Note: $K$ can be any number larger than all the values of $|f''(x)|$, but smaller values of $K$ yield better error bounds.*

The error generated by the Midpoint rule is generally smaller than the Trapezoidal Rule, this is why the midpoint rule gives a much more accurate approximation.
#### Proof:
> The midpoint error (shaded red) is smaller than the trapezoidal error (shaded blue).

> [!example] Example 2: Determining Required Subintervals ($n$)
> **Problem:** How large should we take $n$ in order to guarantee that the Trapezoidal and Midpoint Rule approximations for $\int_1^2 (1/x) \, dx$ are accurate to within $0.0001$?
> 
> **Solution for Trapezoidal Rule:**
> For $f(x) = 1/x$, $f'(x) = -1/x^2$, and $f''(x) = 2/x^3$. Since $1 \le x \le 2$, we have $1/x \le 1$, so $|f''(x)| = |2/x^3| \le 2/1^3 = 2$. Thus, we can take $K=2$.
> Accuracy to within $0.0001$ means $|E_T| < 0.0001$.
> $$ \frac{2(1)^3}{12n^2} < 0.0001 \implies n^2 > \frac{2}{12(0.0001)} \implies n > \frac{1}{\sqrt{0.0006}} \approx 40.8 $$
> Thus, $n = 41$ will ensure the desired accuracy for the Trapezoidal Rule.
> 
> **Solution for Midpoint Rule:**
> $$ \frac{2(1)^3}{24n^2} < 0.0001 \implies n > \frac{1}{\sqrt{0.0012}} \approx 29 $$
> Thus, $n = 30$ ensures accuracy for the Midpoint Rule.

> [!example] Example 3: Midpoint Error Bound for $e^{x^2}$
> **Problem:** (a) Use the Midpoint Rule with $n=10$ to approximate $\int_0^1 e^{x^2} \, dx$. (b) Give an upper bound for the error involved.
> 
> **Solution:**
> (a) With $a=0, b=1$, and $n=10$, $\Delta x = 0.1$.
> $$ \begin{aligned} \int_0^1 e^{x^2} \, dx &\approx \Delta x [f(0.05) + f(0.15) + \cdots + f(0.95)] \\ &= 0.1[e^{0.0025} + e^{0.0225} + \cdots + e^{0.9025}] \approx 1.460393 \end{aligned} $$
> 
> (b) $f(x) = e^{x^2} \implies f'(x) = 2xe^{x^2} \implies f''(x) = (2 + 4x^2)e^{x^2}$.
> Since $0 \le x \le 1$, we have $x^2 \le 1$, so $0 \le f''(x) = (2 + 4x^2)e^{x^2} \le 6e$.
> Taking $K = 6e, a=0, b=1, n=10$:
> $$ |E_M| \le \frac{6e(1)^3}{24(10)^2} = \frac{e}{400} \approx 0.007 $$

### 4. Simpson's Rule

> [!info] Simpson's Rule
> **Simpson's Rule** provides an approximation by using parabolas instead of straight line segments. The interval $[a, b]$ is divided into $n$ subintervals of equal length, where $n$ must be an **even** number.
> $$ \boxed{ \int_a^b f(x) \, dx \approx S_n = \frac{\Delta x}{3} [f(x_0) + 4f(x_1) + 2f(x_2) + 4f(x_3) + \cdots + 2f(x_{n-2}) + 4f(x_{n-1}) + f(x_n)] } $$
> where $n$ is even and $\Delta x =\frac{(b - a)}{n}$.

![[Pasted image 20260906204224.png]]

> [!example] Example 4: Applying Simpson's Rule
> **Problem:** Use Simpson's Rule with $n = 10$ to approximate $\int_1^2 (1/x) \, dx$.
> 
> **Solution:**
> Putting $f(x) = 1/x, n=10$, and $\Delta x = 0.1$ in Simpson's Rule:
> $$ \begin{aligned} \int_1^2 \frac{1}{x} \, dx \approx S_{10} &= \frac{\Delta x}{3} [f(1) + 4f(1.1) + 2f(1.2) + \cdots + 4f(1.9) + f(2)] \\ &= \frac{0.1}{3} \left( \frac{1}{1} + \frac{4}{1.1} + \frac{2}{1.2} + \cdots + \frac{4}{1.9} + \frac{1}{2} \right) \\ &\approx 0.693150 \end{aligned} $$

> [!example] Example 5: Simpson's Rule on Empirical Data
> **Problem:** Use Simpson's Rule to estimate the total amount of data transmitted on a link from midnight to noon, given data traffic $D(t)$ measured in megabits per second at hourly intervals.
> 
> **Solution:**
> Convert $t$ from hours to seconds to match units. $\Delta t = 3600$ seconds, $n=12$.
> $$ \begin{aligned} \int_0^{43,200} A(t) \, dt &\approx \frac{\Delta t}{3} [D(0) + 4D(3600) + 2D(7200) + \cdots + D(43,200)] \\ &\approx \frac{3600}{3} [3.2 + 4(2.7) + 2(1.9) + \cdots + 7.9] \\ &= 143,880 \text{ megabits} \end{aligned} $$

> [!info] Error Bound for Simpson's Rule
> Suppose that $|f^{(4)}(x)| \le K$ for $a \le x \le b$. If $E_S$ is the error involved in using Simpson's Rule, then:
> $$ \boxed{ |E_S| \le \frac{K(b - a)^5}{180n^4} } $$

> [!example] Example 6: Determining $n$ for Simpson's Rule
> **Problem:** How large should we take $n$ in order to guarantee that the Simpson's Rule approximation for $\int_1^2 (1/x) \, dx$ is accurate to within $0.0001$?
> 
> **Solution:**
> If $f(x) = 1/x$, then $f^{(4)}(x) = 24/x^5$. Since $x \ge 1$, we have $1/x \le 1$ and so $|f^{(4)}(x)| = |24/x^5| \le 24$.
> We can take $K = 24$. We choose $n$ such that:
> $$ \frac{24(1)^5}{180n^4} < 0.0001 \implies n^4 > \frac{24}{180(0.0001)} \implies n > \frac{1}{\sqrt[4]{0.00075}} \approx 6.04 $$
> Therefore, $n = 8$ (since $n$ must be even) gives the desired accuracy.

> [!example] Example 7: Simpson's Rule Error Bound for $e^{x^2}$
> **Problem:** (a) Use Simpson's Rule with $n = 10$ to approximate $\int_0^1 e^{x^2} \, dx$. (b) Estimate the error.
> 
> **Solution:**
> (a) If $n = 10$, then $\Delta x = 0.1$:
> $$ \begin{aligned} \int_0^1 e^{x^2} \, dx &\approx \frac{0.1}{3} [f(0) + 4f(0.1) + 2f(0.2) + \cdots + 4f(0.9) + f(1)] \\ &\approx 1.462681 \end{aligned} $$
> 
> (b) The fourth derivative of $f(x) = e^{x^2}$ is $f^{(4)}(x) = (12 + 48x^2 + 16x^4)e^{x^2}$.
> Since $0 \le x \le 1$, we have $0 \le f^{(4)}(x) \le (12 + 48 + 16)e^1 = 76e$.
> Putting $K = 76e, a=0, b=1, n=10$:
> $$ |E_S| \le \frac{76e(1)^5}{180(10)^4} \approx 0.000115 $$
