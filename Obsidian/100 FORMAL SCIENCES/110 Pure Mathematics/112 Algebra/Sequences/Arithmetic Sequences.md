## Arithmetic Sequences (Suite Arithmetique)

> [!info] Definition of an Arithmetic Sequence
> An **arithmetic sequence** is a sequence where each term is generated by adding a fixed constant $d$ to the previous term.
> - $a$: The **first term**.
> - $d$: The **common difference** (the difference between any two consecutive terms).
> 
> **General Form:**
> $$a, a + d, a + 2d, a + 3d, a + 4d, \dots$$
> 
> **Formula for the $nth$ Term:**
> $$a_n = a + (n - 1)d$$

> [!info] Graphical Interpretation
> The graph of an arithmetic sequence $a_n = a + (n-1)d$ consists of isolated points that lie entirely along the straight line $y = dx + (a - d)$, where the common difference $d$ represents the **slope** of the line.
> - If $d > 0$, the terms increase.
> - If $d < 0$, the terms decrease.

> [!example] Example 1: Basic Sequences
> 
> **(a) Positive Difference:**
> - **Given:** $a = 2$, $d = 3$
> - **Sequence:** $2, 2+3, 2+6, 2+9, \dots \implies 2, 5, 8, 11, \dots$
> - **$nth$ Term:** $a_n = 2 + 3(n - 1)$
> 
> **(b) Negative Difference:**
> - **Given Sequence:** $9, 4, -1, -6, -11, \dots$
> - **Analysis:** $d = 4 - 9 = -5$
> - **$nth$ Term:** $a_n = 9 - 5(n - 1)$

---

> [!example] Example 2: Finding Terms from an Explicit Sequence
> 
> Find the common difference, the first six terms, the $nth$ term, and the 300th term of the arithmetic sequence:
> $$13, 7, 1, -5, \dots$$
> 
> **Step-by-Step Solution:**
> 1. **Identify parameters:**
>    - $a = 13$
>    - $d = 7 - 13 = -6$
> 2. **Find the $nth$ term formula:**
>    $$a_n = 13 - 6(n - 1)$$
> 3. **Generate first six terms:**
>    $$13, 7, 1, -5, -11, -17$$
> 4. **Calculate $a_{300}$:**
>    $$a_{300} = 13 - 6(300 - 1) = 13 - 6(299) = 13 - 1794 = -1781$$

---

> [!example] Example 3: Finding Terms from Arbitrary Terms
> 
> The 11th term of an arithmetic sequence is $52$, and the 19th term is $92$. Find the 1000th term.
> 
> **Step-by-Step Solution:**
> 1. **Set up a system of linear equations using $a_n = a + (n-1)d$:**
>    $$a_{11} = a + (11 - 1)d = a + 10d = 52$$
>    $$a_{19} = a + (19 - 1)d = a + 18d = 92$$
> 
> 2. **Solve the system:**
>    $$\begin{cases} a + 10d = 52 \\ a + 18d = 92 \end{cases}$$
>    Subtracting the first equation from the second:
>    $$(a + 18d) - (a + 10d) = 92 - 52$$
>    $$8d = 40 \implies d = 5$$
>    Substitute $d = 5$ back into the first equation:
>    $$a + 10(5) = 52 \implies a + 50 = 52 \implies a = 2$$
> 
> 3. **Formulate the general expression:**
>    $$a_n = 2 + 5(n - 1)$$
> 
> 4. **Calculate $a_{1000}$:**
>    $$a_{1000} = 2 + 5(1000 - 1) = 2 + 5(999) = 2 + 4995 = 4997$$

## Partial Sums of Arithmetic Sequences

### Historical Context: [[Carl Friedrich Gauss|Gauss]]'s Method
To find the sum of the numbers from $1$ to $100$ ($\sum_{k=1}^{100} k$), C. F. Gauss added the sequence to its reverse:

$$\begin{aligned}
S   &= \;\;1\;\; + \;\;2\;\; + \;\;3\;\; + \dots + 98 + 99 + 100 \\
S   &= 100 + 99 + 98 + \dots + \;\;3\;\; + \;\;2\;\; + \;\;1 \\ \hline
2S  &= 101 + 101 + 101 + \dots + 101 + 101 + 101
\end{aligned}$$

Since there are $100$ identical terms:
$$2S = 100(101) = 10,100 \implies S = 5050$$

---

### General Derivation
For any arithmetic sequence $a_k = a + (k - 1)d$:

$$\begin{aligned}
S_n &= \qquad\quad a \qquad\quad + \quad\;\; (a + d) \quad\;\; + \dots + [a + (n - 2)d] + [a + (n - 1)d] \\
S_n &= [a + (n - 1)d] + [a + (n - 2)d] + \dots + \quad\;\; (a + d) \quad\;\; + \qquad\quad a \\ \hline
2S_n &= [2a + (n - 1)d] + [2a + (n - 1)d] + \dots + [2a + (n - 1)d] + [2a + (n - 1)d]
\end{aligned}$$

There are $n$ identical terms, yielding $2S_n = n[2a + (n - 1)d]$.

---

> [!info] Formulas for the $nth$ Partial Sum
> For the arithmetic sequence $a_n = a + (n - 1)d$, the **$nth$ partial sum** $S_n$ is given by either:
> 
> 1. **Using first term ($a$) and common difference ($d$):**
>    $$S_n = \frac{n}{2}[2a + (n - 1)d]$$
> 
> 2. **Using first term ($a$) and $nth$ term ($a_n$):**
>    $$S_n = n\left(\frac{a + a_n}{2}\right)$$
> 
> *Interpretation: The sum is $n$ multiplied by the average of the first and $nth$ terms.*

> [!example] Example 4: Sum of the First 50 Odd Numbers
> 
> Find the sum of the first 50 odd numbers.
> 
> **Step-by-Step Solution:**
> 1. **Identify parameters:**
>    - First term ($a$) = $1$
>    - Common difference ($d$) = $2$
>    - Number of terms ($n$) = $50$
> 2. **Find the 50th term ($a_{50}$):**
>    $$a_n = 1 + 2(n - 1) = 2n - 1$$
>    $$a_{50} = 2(50) - 1 = 99$$
> 3. **Calculate the partial sum ($S_{50}$):**
>    $$S_{50} = 50 \left( \frac{a + a_{50}}{2} \right) = 50 \left( \frac{1 + 99}{2} \right) = 50 \cdot 50 = 2500$$


> [!example] Example 5: Finding a Partial Sum with Unknown $n$
> 
> Find the following partial sum of an arithmetic sequence:
> $$3 + 7 + 11 + 15 + \dots + 159$$
> 
> **Step-by-Step Solution:**
> 1. **Identify known parameters:**
>    - $a = 3$
>    - $d = 4$
>    - Last term ($a_n$) = $159$
> 2. **Determine the number of terms ($n$):**
>    $$159 = 3 + 4(n - 1)$$
>    $$156 = 4(n - 1) \implies 39 = n - 1$$
>    $$n = 40$$
> 3. **Calculate the sum ($S_{40}$):**
>    * **Method 1 (Formula 1):**
>      $$S_{40} = \frac{40}{2} [2(3) + 4(40 - 1)] = 20 [6 + 156] = 20 \cdot 162 = 3240$$
>    * **Method 2 (Formula 2):**
>      $$S_{40} = 40 \left( \frac{3 + 159}{2} \right) = 40(81) = 3240$$
