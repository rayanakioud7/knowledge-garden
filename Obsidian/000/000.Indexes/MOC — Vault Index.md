## 🧭 How to Use This System

- Every **section MOC** (100–800) describes the state of that domain and links to notes.
- **Division MOCs** (e.g. 110, 320) cover one hundred-block in detail.
- **Topic MOCs** (PFE Architecture, Linear Algebra, Trigonometry, Java, Python) go deep on large clusters.
- Legend: 📝 note · ⭐ comprehensive note · 🚧 empty/planned or stub · **(FR)** French-language note.

> [!TIP] Maintenance
> When you add a new note, add one line to the nearest MOC. When you complete an empty folder, flip 🚧 to 📝. A broken-link check should be run after edits — see [[Vault Consistency Audit]] for the known issues list.
